# OpenCV built as XCode Frameworks

These are `opencv2.framework` bundles built for different platforms to be used in XCode projects. As well as a `opencv2.xcframework` to be used in multi-platform projects.

Build command is in [build.sh](build.sh).

Note: iOS armv7 is removed as it failed to build with latest toolchain.

How to use them in an XCode project: 

* [OpenCV for Apple Vision Pro, iPhone, iPad, Mac, and Simulators by lightbuzz](https://lightbuzz.com/opencv/)
* [OpenCV iOS](https://docs.opencv.org/4.12.0/d3/dc9/tutorial_table_of_content_ios.html)
